1. Distributed Node Topology
Time Source (Authority): time.lab.bitsmasher.net

Implementation: ntpsec (NTP Security Project).

Methodology: Stratum 1 local authority utilizing a secure, hardened NTP implementation.

Sync Mode: Broadcast Client. Nodes are configured to listen for time broadcasts on the local subnet to minimize polling overhead and maintain sub-millisecond alignment across the 10.10.8.0/21 infrastructure.

2. Operational Protocols
Sync & Telemetry Integrity
Daemon Requirements: All nodes must run the ntpsec service.

Access Control (Security):

Global: Default IPv4 traffic is restricted to basic time exchange (restrict -4 default).

Cluster Internal: Nodes on the 10.10.8.0/21 range are granted interrogation privileges to allow the Stargate Control Plane to audit clock health.

Logging & Auditing:

Statistics are captured daily in /var/log/ntpstats/.

Key metrics tracked: loopstats (local clock stability), peerstats (upstream server health), and clockstats (hardware clock performance).

Authentication: Authentication is explicitly disabled (disable auth) for local broadcast client operations to ensure high-speed, zero-latency handshakes within the trusted lab environment.
