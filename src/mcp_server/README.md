# FastMCP Server

Fast Micro-Controller Protocol (FastMCP) is a Python library that enables communication between microcontrollers and external devices. This repository contains the code for a FastMCP server.

## Tools

* : A simple tool that takes a name as input and returns a greeting message.
* : A resource that reads the contents of a file named "README.md" and returns it.
